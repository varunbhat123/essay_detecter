# AI Essay Detector

AI Essay Detector is a full-stack application for evaluating admissions essays using linguistic feature analysis and a local AI-likelihood scoring engine. The project combines a modern frontend, a FastAPI backend, sentence-level highlighting, and an evaluation pipeline for measuring detection performance.

## Overview

The system is designed to help review whether an essay appears more likely to be human-written or AI-generated by combining multiple signals, including:

- readability and complexity patterns
- vocabulary and lexical diversity
- repetition and phrase structure
- transition-word frequency
- sentence-level perplexity from a local GPT-2 model
- aggregated heuristic scoring for explainability

The product is intentionally explainable rather than black-box. Instead of asking a model to simply label text, the detector computes a score and highlights sentences that contributed to the decision.

## Stack

- Frontend: Next.js 15, TypeScript, Tailwind CSS
- Backend: Python FastAPI
- ML and NLP: Hugging Face Transformers, PyTorch, scikit-learn, spaCy, NLTK, textstat, pandas, numpy

## System Architecture

The project is split into two primary services:

1. Frontend
   - Located in the frontend directory
   - Built with the Next.js app router
   - Accepts essay text and displays the analysis result
   - Provides a clean UI for text input, counters, and sentence highlighting

2. Backend
   - Located in the backend directory
   - Exposes API endpoints through FastAPI
   - Handles feature extraction, scoring, and evaluation logic
   - Uses a modular architecture for prediction and dataset work

## Feature Extraction

The backend feature extractor computes sentence- and essay-level linguistic features. These include:

- sentence length
- average word length
- vocabulary diversity
- lexical richness
- repeated-word and repeated-phrase ratios
- transition-word frequency
- passive voice count
- readability score
- sentence complexity
- punctuation frequency
- burstiness and entropy

These values are computed from text and then passed into the scoring engine.

## Detection Algorithm

The detection engine is explainable and heuristic-based:

- Sentence-level features are extracted for each sentence.
- Local GPT-2 perplexity is computed for each sentence.
- The scoring engine combines signal weights such as perplexity, lexical diversity, burstiness, readability, and repeated patterns.
- Each sentence receives an AI-likelihood score and a status such as likely_human, suspicious, or likely_ai.
- The overall essay score is the average of sentence scores.
- Results can include sentence highlights with reasons and extracted features.

## Evaluation Module

The evaluation layer allows testing against a real dataset folder and computes:

- Accuracy
- Precision
- Recall
- F1 score
- Confusion matrix
- Full evaluation report

This supports benchmarking detection performance on labeled human and AI essay samples.

## Getting Started

1. Create the Python environment for the backend.
2. Install backend dependencies from backend/requirements.txt.
3. Install frontend dependencies in the frontend directory.
4. Start the FastAPI backend.
5. Start the Next.js frontend.
6. Add or prepare dataset files in the backend dataset folders.
7. Run the evaluation flow against a dataset directory.

## Example Run

Backend:

```bash
cd backend
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

Frontend:

```bash
cd frontend
npm install
npm run dev
```

## Project Status

This project is a working prototype and research-oriented implementation focused on explainable AI detection using linguistic signals. It is suitable for experimentation, educational use, and iterative improvement, but it is not a production-grade detector for high-stakes decisions without further validation and domain-specific tuning.
